# 3H · 로봇 임포트 — URDF 가 담지 않는 것

!!! warning "이 시간의 실습은 최종 검증 전입니다"

**실습 스크립트**: `course_b/day1/11_robot_import.py`

## 학습 목표

- URDF 가 무엇을 담고 **무엇을 안 담는지** 안다
- Articulation(관절체) 구조를 읽는다
- 임포트 직후 **반드시 확인할 것**을 안다

---

## URDF 가 담지 않는 것 ★

URDF 는 로봇의 **기구학**(링크 길이·조인트 축·한계)을 담습니다.
하지만 시뮬레이션에 필요한 것 중 상당수가 빠져 있거나 부정확합니다.

| 항목 | URDF | 확인 필요 |
|---|:---:|---|
| 링크 형상·치수 | ✅ | 단위(m) 확인 |
| 조인트 축·한계 | ✅ | **부호 방향** 확인 |
| 질량·관성 | △ | **0 이거나 엉터리인 경우가 흔함** |
| 조인트 드라이브 게인 | ❌ | **직접 넣어야 함** |
| 충돌 형상 단순화 | △ | 메시 그대로면 매우 느림 |
| 마찰·감쇠 | ❌ | 직접 넣어야 함 |

!!! question "설계 도면과 시뮬레이션 모델은 다릅니다"
    도면에는 질량중심과 관성텐서가 없습니다.
    URDF 도 마찬가지로, "형상"은 있지만 "물성"은 비어 있는 경우가 많습니다.

### 증상으로 원인 찾기

| 증상 | 원인 |
|---|---|
| 로봇이 **흐물흐물 주저앉음** | 드라이브 게인 없음 |
| 시뮬이 **기어감** | 충돌 메시가 너무 촘촘 |
| 로봇이 **이유 없이 튐** | 질량이 0 이거나 관성이 엉터리 |
| 관절이 **반대로 돔** | 조인트 축 부호 |

---

## 임포트

```bash
./python.sh 11_robot_import.py                  # 기본 예제 로봇
./python.sh 11_robot_import.py --urdf my.urdf   # 내 URDF
```

### 임포트 설정에서 짚을 것

```python
cfg.merge_fixed_joints = False   # 고정 조인트를 합치면 링크 이름이 사라져 디버깅이 어려움
cfg.fix_base = True              # 팔 로봇은 베이스를 바닥에 고정
cfg.self_collision = False       # 켜면 느리고 초기 자세에서 자주 터짐
cfg.distance_scale = 1.0         # URDF 가 m 단위가 아니면 여기서 보정
```

!!! tip "`self_collision` 은 처음엔 끄세요"
    로봇이 자기 몸과 충돌하는 것까지 계산하면 훨씬 느리고,
    초기 자세가 조금만 어긋나도 시뮬이 폭발합니다.
    동작이 안정된 뒤에 켜세요.

## 임포트 직후 구조를 훑으세요 ★

스크립트가 자동으로 출력합니다. **이걸 반드시 읽고 넘어가세요.**

```
── 관절체 구조: /World/Robot ──
  링크(리지드바디) 11개
  조인트           9개

  조인트 목록:
    panda_joint1                 <PhysicsRevoluteJoint>  축=Z  한계 [-2.90, 2.90]
    panda_joint2                 <PhysicsRevoluteJoint>  축=Y  한계 [-1.76, 1.76]
    ...

  ⚠️  질량이 0 이거나 없는 링크 2개:
      /World/Robot/panda_link7
      /World/Robot/panda_hand
      → 물리가 불안정해집니다. URDF 의 <inertial> 을 확인하거나
        MassAPI 로 직접 넣으세요.
```

!!! danger "질량 0 경고를 무시하지 마세요"
    여기서 잡지 않으면, 4H 에서 "로봇이 이유 없이 튄다"를
    몇십 분 동안 디버깅하게 됩니다.

### 확인 항목

- [ ] 조인트 수가 예상과 맞는가
- [ ] 조인트 한계가 상식적인가 (라디안 단위)
- [ ] 질량 0 링크가 없는가
- [ ] 로봇 크기가 맞는가 (경계상자로 확인)

## 마지막에 로봇이 무너진다면

스크립트는 임포트 후 60스텝을 돌려 자세가 유지되는지 봅니다.

```
── 60스텝 진행 (자세 유지 확인) ──
완료. 로봇이 바닥으로 무너졌다면 드라이브 게인이 없는 것입니다 → 다음 시간에서 다룹니다.
```

**무너지는 것이 정상입니다.** URDF 에는 드라이브 게인이 없으니까요.
다음 시간에 넣습니다.
