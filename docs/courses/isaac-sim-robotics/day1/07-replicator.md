# 7H · Replicator — 도메인 랜덤화

!!! warning "이 시간의 실습은 최종 검증 전입니다"
    `rep.randomizer` 하위 함수 이름이 버전에 따라 바뀝니다.

**실습 스크립트**: `course_b/day1/15_replicator.py`

## 학습 목표

- 합성 데이터가 왜 필요한지 안다
- **도메인 랜덤화의 역설**을 이해한다
- 랜덤화 규칙을 설계한다

---

## 왜 합성 데이터인가

!!! question "불량품 사진 1,000장을 현장에서 모으려면?"
    몇 달이 걸립니다. 그리고 정작 **드문 불량은 여전히 몇 장뿐**입니다.

    시뮬레이션에서는 **원하는 만큼, 라벨과 함께** 만들 수 있습니다.

| | 현장 수집 | 합성 |
|---|---|---|
| 시간 | 수개월 | 수시간 |
| 라벨링 | 사람이 손으로 | 자동 |
| 희귀 불량 | 거의 못 모음 | 원하는 만큼 |
| 현실성 | 완벽 | **차이가 있음** ← 문제 |

마지막 줄이 이 과정의 절반을 차지하는 주제입니다.

---

## 역설적인 핵심 ★

시뮬레이션 이미지는 실사와 다릅니다. 그대로 학습시키면 현장에서 실패합니다
(**sim-to-real gap**).

해법은 직관에 어긋납니다.

!!! success "더 사실적으로 만들려 하지 말고, 더 다양하게 만든다"
    조명·재질·색·포즈·카메라 각도를 무작위로 흔들면,
    모델은 **"이 모든 변형에서도 변하지 않는 것"**(=물체의 형태)을 배웁니다.

    그러면 **실사도 그 변형 중 하나**가 됩니다.

| 랜덤화 대상 | 효과 |
|---|---|
| 조명 세기·색·방향 | 공장 조명 변화에 강해짐 |
| 물체 재질·색 | 자재 로트 차이에 강해짐 |
| 물체 위치·회전 | 배치 변화에 강해짐 |
| 카메라 위치·초점 | 설치 오차에 강해짐 |
| 배경·방해물 | 실제 잡동사니에 강해짐 |

!!! warning "너무 흔들면 아무것도 못 배웁니다"
    이 균형이 다음 시간과 Day 3 의 주제입니다.
    `--preset extreme` 으로 과도하게 흔든 경우를 직접 보게 됩니다.

---

## `semantics` 를 빼먹지 마세요 ★

```python
part = rep.create.cube(
    position=(0.0, 0.0, 0.1),
    scale=(0.25, 0.25, 0.15),
    semantics=[("class", "cracked_part")],     # ← 라벨의 근원
)
```

!!! danger "이걸 빼먹으면 이미지만 나오고 라벨이 빕니다"
    **파일 개수는 정상**이라 눈치채기 어렵습니다.
    8H 의 검수에서 "라벨 비어 있음 11.2%" 같은 결과로 드러납니다.

## 랜덤화 규칙

```python
with rep.trigger.on_frame(num_frames=50):
    with light:
        rep.modify.attribute("inputs:intensity", rep.distribution.uniform(300, 2000))
    with part:
        rep.modify.pose(
            position=rep.distribution.uniform((-0.6, -0.3, 0.08), (0.6, 0.3, 0.18)),
            rotation=rep.distribution.uniform((0, 0, -180), (0, 0, 180)),
        )
    with camera:
        rep.modify.pose(
            position=rep.distribution.uniform((-0.3, -1.9, 0.9), (0.3, -1.3, 1.5)),
            look_at=(0.0, 0.0, 0.1),
        )
```

## 비교군을 꼭 만드세요 ★

```bash
./python.sh 15_replicator.py --frames 50                    # 랜덤화 적용
./python.sh 15_replicator.py --frames 50 --no-randomize     # 비교군
```

두 폴더의 이미지를 **눈으로 비교**하세요.

!!! tip "랜덤화 없는 데이터가 얼마나 단조로운지 봐야 왜 필요한지 체감합니다"
    50장이 거의 같은 그림입니다. 이걸로 학습하면 모델이
    "이 조명, 이 각도"만 아는 것이 됩니다.

Day 3 18H 에서 이 차이를 **숫자로** 확인합니다.

| 모델 | 학습 데이터 | 시뮬 | 현장 |
|---|---|---:|---:|
| A | 랜덤화 없음 | 100.0% | 67.3% |
| B | 랜덤화 적용 | 99.8% | **96.5%** |

## 정리

| 항목 | 핵심 |
|---|---|
| **합성 데이터** | 원하는 만큼, 라벨과 함께 |
| **도메인 랜덤화** | 사실적으로가 아니라 **다양하게** |
| **`semantics`** | 빼먹으면 라벨이 빈다 |
| **비교군** | 없으면 효과를 체감 못 함 |
