## 오늘의 시간 운영 ★

**학습은 몇십 분씩 걸립니다.** 앉아서 기다리면 하루가 날아갑니다.

```
13H  각자 학습을 걸어 둔다 ────────────────┐
14H  준비된 로그로 진단을 배운다            │ 학습은 백그라운드로 계속
15H  자기 학습 결과가 나오면 그것으로 평가 ─┘
16H  커스텀 태스크 착수 (학습은 또 백그라운드)
```

!!! tip "학습을 걸어 두고 다음으로 넘어가세요"
    끝나기를 기다리지 마세요. 14H 노트북이 **4가지 학습 양상을 흉내 낸
    모의 로그**를 만들어 주므로, 자기 결과가 없어도 진단을 배울 수 있습니다.
