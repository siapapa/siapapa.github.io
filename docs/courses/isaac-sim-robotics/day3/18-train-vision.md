# 18H · 합성데이터로 모델 학습 — 그리고 함정 하나

!!! success "이 시간은 실행 검증 완료 · GPU 불필요"
    CPU 로 몇 초면 학습됩니다.

**실습 노트북**: `course_b/day3/25_train_vision.ipynb`

## 학습 목표

- 합성 데이터로 분류 모델을 학습시킨다
- 도메인 랜덤화가 학습에 주는 영향을 본다
- **시뮬 정확도가 높다고 안심하면 안 되는 이유**를 체감한다

---

## 순서가 중요합니다

먼저 **시뮬 성적만** 봅니다.

```
모델                             시뮬 정확도
A (랜덤화 없이 학습)                  100.0%
B (랜덤화하여 학습)                    99.8%
```

!!! question "어느 쪽이 좋아 보입니까?"
    A 입니다. 100% 니까요.

이제 **현장 데이터**에서 재 봅니다.

```
모델                               시뮬         현장          갭
A (랜덤화 없이)                   100.0%      67.3%      32.7%p
B (랜덤화 적용)                    99.8%      96.5%       3.3%p
```

!!! danger "이것이 sim-to-real 갭입니다"
    A 는 시뮬에서 완벽하지만 현장에서 **3분의 1을 틀립니다.**
    B 는 시뮬 성적을 0.2%p 내주고 현장에서 **29%p 를 얻었습니다.**

    **"더 사실적으로"가 아니라 "더 다양하게"** 가 해법인 이유입니다.

---

## 밝기 분포를 보세요

```
밝기 분포 (0.0 ─────────────────── 1.0)
  시뮬(랜덤화 X)               ▄▇█▇▆▇▆
  시뮬(랜덤화 O)     ▃▆▆▇▆▆▆▆▄▇█▆▅▆▅▇▆▆▇▆▇▇▅▇▇▃
  현장            ▂▅▇▆▆▆▆▅▇▅▆▆▄█▅▇▇▆▅▅▇▇▅▅▄▅
```

랜덤화 없는 시뮬은 밝기 폭이 **좁습니다.** 현장은 넓습니다.
모델이 "밝기 0.5 근처면 이런 것"을 외워버리면 현장에서 무너집니다.

---

## 함정 — 모델 구조가 과제를 따라가야 합니다 ★

!!! quote "이 교재를 만들 때 실제로 겪은 일"
    처음에 마지막 층을 `AdaptiveAvgPool2d(1)` 로 두었더니
    정확도가 **42%(무작위 수준)** 에 머물렀습니다.

    전역 평균이 특징맵을 **숫자 하나로 뭉개서**,
    가로 막대와 세로 막대를 **구분할 수 없게** 된 것입니다.

```python
# ❌ 방향 정보가 사라짐
nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.AdaptiveAvgPool2d(1),
nn.Flatten(), nn.Linear(32, 3),

# ✅ 위치 정보가 남음
nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 8→4
nn.Flatten(),                        # 32×4×4 = 512
nn.Linear(512, 64), nn.ReLU(), nn.Linear(64, 3),
```

**방향이 중요한 과제에서는 평균 풀링을 쓰지 마세요.**

## 클래스별로 보세요

전체 정확도만 보면 **무엇을 놓치는지** 모릅니다.

```
모델                     good     dented    cracked
A 현장                   89.3%     52.1%      61.4%
B 현장                   98.1%     95.7%      95.8%
```

!!! danger "불량을 정상으로 판정하는 것이 훨씬 비쌉니다"
    A 는 `dented` 를 절반 가까이 놓칩니다.
    전체 67% 라는 숫자 뒤에 이런 편중이 숨어 있습니다.

## 정리

| 항목 | 핵심 |
|---|---|
| **시뮬 정확도** | 높다고 안심하면 안 된다 |
| **도메인 랜덤화** | 시뮬 조금 내주고 현장 크게 얻는다 |
| **모델 구조** | 과제가 요구하는 정보를 보존해야 함 |
| **클래스별 지표** | 전체 정확도가 편중을 숨긴다 |
