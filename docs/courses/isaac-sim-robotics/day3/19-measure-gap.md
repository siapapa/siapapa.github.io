# 19H · 갭 측정 — 현장에 내보내도 되는가

!!! success "이 시간은 실행 검증 완료 · GPU 불필요"

**실습 노트북**: `course_b/day3/26_measure_gap.ipynb`

## 학습 목표

- 갭을 **여러 조건에서** 재고 경향을 읽는다
- 정확도가 아니라 **운영 지표**로 판단한다
- "배포 가능/불가"를 근거와 함께 말한다

---

## 갭은 하나의 숫자가 아닙니다 ★

조명이 얼마나 다른지, 노이즈가 얼마나 심한지에 따라 달라집니다.
**어느 조건까지 견디는가**를 재야 합니다.

```
조명 폭에 따른 정확도 (노이즈 0.05 고정)
   조명 폭      모델 A      모델 B        차이
      0.1      95.5%      96.0%       0.5%p
      0.3      88.2%      96.2%       8.0%p
      0.5      76.8%      95.8%      19.0%p
      0.7      65.3%      95.5%      30.2%p
      0.9      58.1%      94.9%      36.8%p
```

!!! question "조명 폭이 좁을 때는 두 모델이 비슷합니다"
    갭은 **조건이 시뮬에서 멀어질수록** 벌어집니다.

    그래서 **"우리 현장 조건이 시뮬과 얼마나 다른가"** 를 먼저 알아야
    갭을 예측할 수 있습니다.

---

## 운영 지표로 바꿔 말하세요 ★

정확도는 관리자에게 의미가 약합니다.

| 지표 | 의미 | 비용 |
|---|---|---|
| **불량 유출** (미검출) | 불량을 정상으로 판정 | 고객 클레임 — **가장 비쌈** |
| **과검** (오검출) | 정상을 불량으로 판정 | 불필요한 재검사·폐기 |

```
모델                     정확도       불량유출        과검
A (랜덤화 없이)          67.3%        56.0%       40.3%
B (랜덤화 적용)          96.5%         2.1%        3.8%
```

!!! quote "'정확도 96%' 보다 '불량 유출 2.1%, 과검 3.8%' 가 현장 대화입니다"
    이 번역을 못 하면 아무리 좋은 모델도 채택되지 않습니다.

---

## 기준은 미리 정하세요 ★

!!! danger "결과를 보고 기준을 정하면 자기 결과에 맞춘 기준이 됩니다"

```python
MAX_ESCAPE = 0.02        # 불량 유출 2% 이하
MAX_OVER   = 0.15        # 과검 15% 이하
MIN_ACC    = 0.85
```

판정:

```
배포 기준: 불량유출 ≤2%, 과검 ≤15%, 정확도 ≥85%

❌ A (랜덤화 없이) — 배포 불가
     불량유출 56.0% > 2%
     과검 40.3% > 15%
     정확도 67.3% < 85%
✅ B (랜덤화 적용) — 배포 가능
```

**기준을 먼저 선언하고 그다음에 판정하는 순서**를 지키세요.
현장과 협의해 정하는 값이고, 라인마다 다릅니다.

---

## 임계값 튜닝 — 재학습 없이 운영점 옮기기

분류 모델은 확률을 냅니다. "정상" 판정 문턱을 높이면
**불량 유출은 줄고 과검은 늘어납니다.**

```
문턱 T    불량유출     과검
 0.50      2.1%      3.8%
 0.70      1.2%      7.4%
 0.90      0.4%     18.2%
```

!!! success "이것이 현장에서 실제로 하는 튜닝입니다"
    모델을 다시 학습시키지 않고도 운영 지점을 옮길 수 있습니다.
    가장 값싼 수단이니 먼저 시도하세요.

## 발표용 요약

```
■ 선택 모델: B (랜덤화 적용)
■ 현장 조건 정확도 96.5%
■ 불량 유출률 2.1% (17/800건)
■ 과검률 3.8% (30/800건)
■ 한계: 합성 데이터만으로 학습했으며, 실제 현장 이미지 검증이 필요함
```
