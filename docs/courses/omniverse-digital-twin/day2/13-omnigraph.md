# 13H · OmniGraph — 코드 없이 반응 로직

!!! danger "이 시간은 Kit 이 필수입니다"
    사양이 부족하면 페어의 화면을 함께 보세요.
    14~15H 는 다시 GPU 없이 진행합니다.

## 학습 목표

- 노드를 이어 이벤트 반응 로직을 만든다
- **언제 OmniGraph 를 쓰고 언제 파이썬을 쓸지** 판단한다

---

## Action Graph — 노드를 선으로 잇습니다

```
[OnTick] → [ReadPrimAttribute]  → [Greater]  → [Branch]
            motorTemp              70            ├─ True  → [SetPrimAttribute] 빨강
                                                 └─ False → [SetPrimAttribute] 초록
```

!!! tip "PLC 래더 로직을 아신다면"
    감각이 비슷합니다. 조건을 만족하면 출력이 나가는 구조입니다.
    코드를 쓰지 않고 흐름을 그림으로 표현합니다.

## 언제 무엇을 쓰나

| 쓰는 곳 | 도구 |
|---|---|
| 씬 안에서 즉각 반응하는 로직 (알람·색·간단한 애니메이션) | **OmniGraph** |
| 외부 시스템 연동·복잡한 계산·대량 데이터 | **Python** |

12H 에서 7,200개 샘플을 넣은 것 같은 일은 파이썬이 맞습니다.
"온도가 70 을 넘으면 빨갛게" 같은 것은 그래프가 맞습니다.

---

## 실습

1. `Window` → `Visual Scripting` → `Action Graph`
2. `OnTick` 노드 배치 — 매 프레임 실행
3. `ReadPrimAttribute` 로 `Conveyor_A` 의 `telemetry:motorTemp` 읽기
4. `Greater` 로 `70` 과 비교
5. `Branch` → `SetPrimAttribute` 로 `displayColor` 변경
6. 타임라인 재생 → **3691 프레임 근처에서 색이 바뀌는지** 확인

12H 에서 넣은 데이터가 있으므로, 고장 시점에 실제로 반응합니다.

!!! warning "이 절차는 개강 전 최종 확인 중입니다"
    Omniverse 는 버전에 따라 노드 이름과 메뉴 위치가 달라집니다.
    실제 화면과 다르면 강사에게 알려 주세요.

## 흔한 문제

| 증상 | 원인 |
|---|---|
| 노드를 못 찾음 | 검색창에 이름 일부만 입력해 보세요 |
| 값이 안 읽힘 | 프림 경로가 정확한지 확인 |
| 색이 안 변함 | `displayColor` 는 배열입니다 — 값 하나가 아니라 `[(r,g,b)]` |
| 그래프가 안 도는 것 같음 | 타임라인이 재생 중인지 확인 (`OnTick` 은 재생 중에만) |
