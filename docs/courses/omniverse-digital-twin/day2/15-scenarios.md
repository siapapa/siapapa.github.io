## 디지털트윈의 값어치

!!! quote "예쁜 3D 가 아니라 '해 보기 전에 알 수 있다' 입니다"
    설비를 실제로 세우지 않고 조건을 바꿔 결과를 봅니다.
    이것이 안 되면 비싼 3D 뷰어일 뿐입니다.

## 시드를 고정하세요

같은 조건은 같은 결과가 나와야 합니다.
그래야 차이가 **조건 때문인지 우연인지** 구분됩니다.

```python
def run_scenario(duration=7200, fault_at=None, seed=42):
    state = LineState(rng=random.Random(seed))
    out, t = [], 0.0
    while t < duration:
        out.append(state.step(t, 1.0, fault_at))
        t += 1.0
    return out

baseline = run_scenario(fault_at=None)      # 고장 없음
faulted  = run_scenario(fault_at=3600)      # 1시간 뒤 고장
```

## 무엇을 볼 것인지 먼저 정합니다

**지표를 정하고 시뮬을 돌립니다.** 돌려 놓고 뭘 볼지 고민하면
자기 결과에 유리한 지표를 고르게 됩니다.

| 지표 | 의미 |
|---|---|
| 가동률 | 멈추지 않고 돈 시간의 비율 |
| 평균 사이클타임 | 한 개 생산에 걸리는 시간 |
| 생산량 | 사이클타임의 역수를 적분 |
| 평균 통과율 | 품질 |
| 최고 온도 | 설비 부담 |

```
     시나리오       가동률(%)   평균사이클(s)   생산량(개)   평균통과율(%)  최고온도(°C)
     고장 없음          97.4          9.2         789         99.2         48.3
     고장 발생          97.1         18.7         557         93.4         95.0
```

## what-if — 몇 분 안에 조치해야 하는가 ★

!!! question "온도 경보를 받고 몇 분 안에 조치하면 손실이 얼마나 줄어드나?"
    정비팀과 협상할 때 필요한 숫자입니다.

```
  대응시간          생산량         손실       최고온도
     무대응          557         232         95.0
      30분          676         113         95.0
      15분          739          50         95.0
       5분          780           9         92.9
       1분          789           0         64.3
```

읽는 법:

- **무대응**이면 232개(29%)를 잃습니다
- **15분 안에** 조치하면 손실이 50개로 — **78% 감소**
- **1분 안에** 조치하면 온도가 경보선(70°C)조차 넘지 않습니다

!!! success "이 표가 발표에 들어갈 슬라이드입니다"
    **"온도 경보 후 15분 안에 조치하면 생산 손실을 78% 줄일 수 있다"**

    3D 화면보다 이 한 줄이 의사결정을 움직입니다.
    관리자는 회전하는 3D 모델에 예산을 주지 않습니다. 이 숫자에 줍니다.
