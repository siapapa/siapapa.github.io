## 프로젝트 — 공용 씬을 내 도메인으로

수업 실습은 전원 `SmartFactory-01` 로 진행하고,
**프로젝트는 그 씬을 자기 현장으로 변형**합니다.

빈 화면에서 시작하지 않으므로 16시간 안에 결과물이 나옵니다.

| 원본 요소 | 변형 예시 |
|---|---|
| 컨베이어 라인 | 도장 라인 · 포장 라인 · 물류 소팅 |
| 검사 스테이션 | 비전 검사 · 계측 · 중량 선별 |
| 버퍼 적재부 | 자동창고 · 파레트 스택 |
| 모터 온도 태그 | 진동 · 전류 · 압력 |

!!! tip "현장 데이터가 없어도 됩니다"
    실제 설비 데이터를 가진 분은 거의 없습니다.
    **모의 데이터 생성기**가 실습 자산에 포함되어 있어, 내 태그 구성에 맞춰
    데이터를 만들어 쓸 수 있습니다.

## 최종 산출물 요건

발표 때 아래를 보여 주면 통과입니다.

1. 자기 도메인으로 변형한 **USD 씬** — 레이어가 **2장 이상 분리**되어 있을 것
2. **데이터 연동** — 실제 또는 모의 데이터가 흘러 들어와 씬이 반응할 것
3. **상태 시각화** — 정상/경고/이상이 눈으로 구분될 것
4. **질문 1개에 대한 답** — 아래 과제 #1 의 질문 중 하나를 트윈으로 답해 보일 것

---

## 과제 #1 — 내일 시작 시 제출

```markdown
## 1. 대상 설비/공정
- 무엇을: (예: 2호기 포장 라인)
- 왜 이것을:

## 2. 트윈으로 답하고 싶은 질문 5개
1. (예: 어제 오후 포장 불량이 늘어난 원인은 어느 설비인가?)
2. …

## 3. 필요한 데이터 태그
| 태그 이름 | 단위 | 범위 | 경고 임계 | 나쁜 방향 |
|---|---|---|---|---|
|  |  |  |  | 초과 / 미만 |

## 4. 레이아웃 스케치
(손그림 사진도 무방)
```

### 질문을 잘 쓰는 법 ★

**데이터로 답할 수 있는 형태**여야 합니다.

| ❌ 이런 질문 | ✅ 이런 질문 |
|---|---|
| 라인을 개선하고 싶다 | 어느 설비가 병목인가 |
| 품질을 높이고 싶다 | 불량률이 오른 시각과 그때 이상했던 태그는 |
| 효율적으로 운영하고 싶다 | 컨베이어 속도를 10% 올리면 버퍼가 넘치는가 |

!!! quote "평가 포인트"
    질문이 **구체적이고 데이터로 답할 수 있는가** 를 봅니다.
    좋은 질문 하나가 좋은 트윈 하나를 만듭니다.

### 태그 표에서 "나쁜 방향" 을 꼭 채우세요

태그마다 나쁜 방향이 다릅니다.

- 모터 온도 — **높으면** 이상
- 통과율 — **낮으면** 이상

이걸 빠뜨리면 정상 운전이 전부 경고로 잡힙니다.
내일 11H 에서 실제로 그 문제를 다룹니다.
