## 공용 실습 씬 — `SmartFactory-01`

전원이 **같은 씬**으로 실습합니다. 각자 자산을 준비하는 부담이 없고,
질문과 디버깅이 공유됩니다.

```
/World
├─ Line01
│  ├─ Conveyor_A          속도 · 모터온도   ← 고장이 나는 쪽
│  ├─ Conveyor_B          속도 · 모터온도   ← 정상 비교군
│  ├─ InspectionStation   통과율
│  ├─ Buffer              재고 수량
│  └─ RobotArm_01         (다음 과정에서 움직입니다)
└─ AGV_Path
```

### 데이터에 답이 숨어 있습니다

모의 데이터에 **인과관계**를 심어 두었습니다.

```
모터 온도 상승 → 보호 로직이 감속 → 사이클타임 증가
                                 → 통과율 하락
                                 → 버퍼 고갈
```

"왜 오후에 통과율이 떨어졌나?" 를 추적하면 모터 온도에 도달합니다.
`Conveyor_B` 는 정상을 유지하므로 **비교군**이 됩니다.

### 프로젝트는 이 씬을 자기 도메인으로 변형합니다

| 원본 | 변형 예시 |
|---|---|
| 컨베이어 라인 | 도장 라인 · 포장 라인 · 물류 소팅 |
| 검사 스테이션 | 비전 검사 · 계측 · 중량 선별 |
| 버퍼 적재부 | 자동창고 · 파레트 스택 |
| 모터 온도 태그 | 진동 · 전류 · 압력 |

빈 화면에서 시작하지 않으므로 16시간 안에 결과물이 나옵니다.
