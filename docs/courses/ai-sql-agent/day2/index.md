# Day 2 — Text-to-SQL 상담사 (9~12H)

!!! info "학습 목표"
    Text-to-SQL 정확도를 높이고, 멀티턴 상담사를 만들어 Gradio UI로 배포합니다.

## 용어 사전

| 용어 | 설명 |
|---|---|
| **프롬프트** | AI에게 보내는 "지시서" |
| **토큰** | AI가 텍스트를 읽는 단위 (한글 1자 ≈ 1~2토큰) |
| **Few-shot** | AI에게 예시를 보여주는 것 |
| **가드레일** | AI가 위험한 행동을 못하게 막는 안전장치 |
| **멀티턴** | 이전 대화를 기억하는 채팅 |

## 타임라인

| 시간 | 주제 | 핵심 키워드 |
|:---:|---|---|
| **9H** | 제안서 피어리뷰 | 스키마 검증기, 피어리뷰 |
| **10H** | Text-to-SQL 심화 | 커스텀 프롬프트, Few-shot |
| **11H** | 멀티턴 상담사 | ChatState, SQLGuardrail |
| **12H** | Gradio UI | ChatInterface, share=True |
